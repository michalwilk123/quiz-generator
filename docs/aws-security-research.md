# CLF-C02 Security and Compliance research

Researched on 2026-10-11. Deliverable: 75 original English questions in the Security and Compliance section of `src/quizes/aws-clf-c02.json`, with 60 single-answer items and 15 multiple-response items. Every item explains the correct choice and each distractor and includes HTTPS links to AWS factual sources. The questions cover all four Domain 2 task statements; this domain represents 30% of scored CLF-C02 content. [Current AWS exam guide](https://docs.aws.amazon.com/aws-certification/latest/cloud-practitioner-02/cloud-practitioner-02.html), [Domain 2 outline](https://docs.aws.amazon.com/aws-certification/latest/cloud-practitioner-02/cloud-practitioner-02-domain2.html).

## Style evidence and decisions

Visited the [official public AWS sample PDF](https://d1.awsstatic.com/training-and-certification/docs-cloud-practitioner/AWS-Certified-Cloud-Practitioner_Sample-Questions.pdf). It identifies itself as CLF-C01 and dates to 2020, so it was used only to observe question construction. It contains concise service-selection prompts, direct responsibility questions, and short answer choices. The current exam guide establishes four choices for a single-answer item and multiple-response items with explicit required selections. These observations informed the structure, not copied stems or answer sets.

Also visited [CloudCertPrep's free security practice page](https://www.cloudcertprep.io/aws/clf-c02/security-and-compliance) and [Tech Exam Lexicon's original sample page](https://techexamlexicon.com/aws/clf-c02/sample-questions/) for broad style comparison. The former describes its bank as original and MIT licensed; the latter describes its samples as original. Neither was used as a factual authority or a source of question text. Their claims of matching the real exam cannot independently establish real exam similarity.

The written questions use short business situations or direct conceptual prompts, one clear deciding requirement, and plausible neighboring services as distractors. Examples of the distinctions covered include Artifact versus Audit Manager, Config versus CloudTrail versus CloudWatch, GuardDuty versus Inspector versus Macie, and WAF versus Shield. Multiple-response stems specify `(Select TWO.)` or `(Select THREE.)`. No code, architecture design exercise, implementation procedure, recalled real exam content, or unscored placeholder question is included. The chosen 20% multiple-response proportion is an editorial practice-bank choice, not a published AWS exam proportion.

## Current terminology and limits

- Human access follows the current recommendation for federation/Identity Center and temporary credentials. Questions about IAM users describe existing users or use cases requiring long-term credentials rather than recommending them universally. [IAM guidance](https://docs.aws.amazon.com/IAM/latest/UserGuide/best-practices.html).
- Account closure and root email questions explicitly concern standalone accounts outside Organizations. Current documentation permits central management of some member-account tasks and removal of member-account root credentials, so an unconditional root-only claim would be inaccurate. [Root user documentation](https://docs.aws.amazon.com/IAM/latest/UserGuide/id_root-user.html).
- Root MFA configuration does not configure MFA for IAM users. Root questions acknowledge credentials exist, avoiding the assumption that every organization member account retains root credentials. [MFA documentation](https://docs.aws.amazon.com/IAM/latest/UserGuide/id_credentials_mfa.html).
- The bank uses the current name AWS Security Hub CSPM for posture checks and finding aggregation. [Security Hub documentation](https://docs.aws.amazon.com/securityhub/latest/userguide/what-is-securityhub.html).
- Shield Advanced response-team access is described subject to eligibility/support requirements. Baseline Shield Standard is kept distinct from paid Advanced protection; preview capabilities are not tested. [Shield FAQ](https://aws.amazon.com/shield/faqs/).
- Audit Manager organizes evidence; it does not certify customer compliance. Compliance-program service coverage does not automatically make a customer's workload compliant. [Audit Manager](https://docs.aws.amazon.com/audit-manager/latest/userguide/what-is.html), [Shared responsibility](https://aws.amazon.com/compliance/shared-responsibility-model/).
- An attempted legacy Lambda security URL and a Lambda whitepaper URL redirected to a documentation index without usable security content. Lambda questions therefore remain at the broad shared-responsibility/workload-permission level supported by the shared-responsibility page and IAM workload guidance. An incorrect initial IAM policy-evaluation URL was replaced with the working `reference_policies_evaluation-logic.html` URL.
